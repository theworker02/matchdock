# matchdock

Match validation gates for dock inputs before they hit prod.

**Site:** https://theworker02.github.io/matchdock/

## Install / run

```bash
git clone https://github.com/theworker02/matchdock.git
cd matchdock
node src/cli.js
node --test
```
